# 资产收集分级工作流（Compliant Asset Collection Workflow）

> 合规优先 · 分级管控 · 最小必要 · 全程留痕 · 熔断保护
>
> 一款面向**授权安全测试**（安全服务 / SRC 漏洞挖掘）的资产收集工具。
> 与常见收集工具的区别：把「对象定级 → 分级操作矩阵 → 审计留痕」的安服方法论固化进工具——
> 先定级，工具再按等级自动限速、对高敏感目标强制特批，探测异常时自动熔断停止。

## 功能特性

- **完整 P0–P6 工作流**：授权检查 → 决策树定级 → 被动收集 → 分级主动探测 → 资产清单导出（CSV + Markdown）
- **四级对象定级**：高敏感 / 特殊敏感 / 一般对象 / 自定义，决策树引导，等级决定速率与审批门槛
- **被动收集**：crt.sh 证书透明度、HackerTarget 被动 DNS；可选接入 Hunter / FOFA 测绘 API（Key 随用随填不落盘），支持测绘平台 CSV 导出文件导入合并
- **分级主动探测**：子域名爆破（内置字典）、存活探测 / 端口扫描、Web 指纹识别（Server / X-Powered-By / 标题）、目录扫描
- **熔断保护**：连续超时 / 连续 403/429 / 基线主机失联时自动停止全部主动探测，已收集结果照常导出（只停不绕）
- **审计留痕**：`audit.log` 全程 JSON 行记录操作，API Key 脱敏
- **双模式**：Web 图形界面（仅监听 127.0.0.1）+ 命令行
- **零依赖**：Python 3.8+ 标准库，无需安装任何第三方包

## 快速开始

```bash
# Web 图形界面（推荐）
python asset_web.py
# 浏览器打开 http://localhost:8000

# CLI 交互式向导
python asset_workflow.py

# CLI 命令行模式
python asset_workflow.py --domain example.com --level general --authorized
```

## 分级操作矩阵

| 探测项 | 高敏感 | 特殊敏感 | 一般对象 | 自定义 |
|---|---|---|---|---|
| 子域名爆破 | 特批后限速 | 限速 1s | 0.2s | 低速 2s |
| 存活探测 / 端口扫描 | 特批后限速 | 限速 1s | 0.2s | 低速 2s |
| Web 指纹识别 | 特批后限速 | 限速 1s | 0.2s | 低速 2s |
| 目录扫描 / 爬虫 | 特批后限速 | 限速 1s | 0.2s | 低速 2s |

不勾选任何探测项即为纯被动收集（零接触目标）。

## 熔断器

| 触发条件 | 阈值 |
|---|---|
| 连续连接超时 / 被重置 | 5 次 |
| 连续 HTTP 403 / 429 | 3 次 |
| 基线主机（主站）失联 + 连续异常 | 立即 |

设计红线：**只停不绕**——熔断后不做自动重试 / 降速 / 换 IP，由人工判断下一步。
